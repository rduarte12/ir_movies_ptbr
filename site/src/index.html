Mais de 8 mil filmes para buscar

Os filmes vêm do The Movie Database (TMDB). Entre os mais populares, ficaram os que têm resumo (sinopse) em português.

Como usar

  1. 1
    Descreva um filme do seu jeito, ou toque num exemplo.
  2. 2
    Veja os pôsteres, do mais ao menos parecido com a sua frase.
  3. 3
    Toque num pôster para ver os detalhes do filme.
  4. 4
    Logo abaixo, descubra por que ele apareceu.

Como a máquina lê a sua frase

Palavras raras pesam mais

Uma palavra que aparece em quase todo filme, como “vida”, ajuda pouco. Uma palavra rara, como “tubarão”, é uma pista forte. Por isso ela vale mais pontos.

idf = ln( (1 + N) / (1 + df) ) + 1

Para os curiosos: N é o total de filmes e df é em quantos filmes a palavra aparece. Quanto menos filmes, maior o peso (idf).

Quão parecidas são a frase e a sinopse?

O buscador transforma a sua frase e cada sinopse em listas de pesos, um por palavra. Essas listas são vetores, que dá para desenhar como setas. Quanto mais as setas apontam para o mesmo lado, mais parecidos são os textos. Essa medida se chama cosseno.

Mexa nos controles. Aqui são só duas palavras, para caber no desenho; no FilmUSP, cada seta tem uma direção para cada palavra conhecida (mais de 20 mil).

Quando as palavras não bastam

Contar palavras iguais tem limite: quem procura “rato cozinheiro” não acha uma sinopse que fala em “ratinho chef”. Por isso, um modelo de linguagem transforma cada sinopse em um vetor de características: 384 números que resumem o sentido do texto. A sua frase vira outro vetor, e o FilmUSP procura as sinopses de sentido mais próximo.

Juntando palavras e sentido

pontos = 1/(k + posição no sentido) + 1/(k + posição nas palavras)
